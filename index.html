A Hack Club YSWS about making Hackatime plugins

Sample leaderboard (times shown in UTC). The current time is UTC.

Hackatime is Hack Club's time-tracking tool. We use it to track the time you spend on your amazing projects.

There are two problems to solve, and we need your help.

1. There are many tools hackers use that we can't track yet. We need plugins that track time spent on tools with hacker value.

2. The Hackatime API is so cool! It would be great to have more programs that use it.

So we challenge you to make one of these: a plugin or a tool using the Hackatime API.

As thanks, you can choose an item from our shop!

P.S. If your plugin gets adopted, you get a special bonus!
